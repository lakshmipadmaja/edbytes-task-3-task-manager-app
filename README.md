# EdBytes Task 3 – Task Manager App

## About the Project
This is a simple Task Manager application developed as part of the EdBytes Full Stack Development program.

The application allows users to add tasks, delete tasks, and save their tasks using browser Local Storage.

## Features
- Add new tasks.
- Prevent adding empty tasks.
- Delete individual tasks.
- Save tasks automatically using Local Storage.
- Restore saved tasks after refreshing the page.

## Technologies Used
- HTML
- CSS
- JavaScript
- Browser Local Storage

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Add and delete tasks to test the application.
5. Refresh the page to verify that saved tasks are still available.

## Testing

- Tested deleting tasks.
- Tested empty task input.
